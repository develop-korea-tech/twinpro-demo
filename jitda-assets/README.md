# jitda-assets

짓다(jitda) 팀 프로젝트에서 쓰는 TWIN PRO 이미지 파일입니다. `index.html`의 `EQ_PHOTO`, `EQ_ART`, `BK_THUMBS`에서 그대로 추출했습니다.

- 한 번에 쓰기: `twinpro_images.js` 를 `<script>`로 불러오면 `window.EQ_PHOTO`, `window.EQ_ART`, `window.BK_THUMBS`가 생깁니다.
- 개별 파일: `eq_photo_P01.webp` (CNC 절단기), `P02` 취부 작업대, `P03` 용접 작업셀, `P04` 검사 스테이션, `P05` 도장 작업구역, `P06` 블록 운반차, `SP` 용접기, `block`, `ship_build`, `ship_done`
- 주소: `https://develop-korea-tech.github.io/twinpro-demo/jitda-assets/<파일명>`
